APIDescription
GET cliente/get

Todos os dados dos clientes da empresa logada

Devolve uma lista dos últimos 10 cupons do cliente passado como parametro

GET cliente/buscarapida/{busca}/{codusuariopdv}/{codfilial}

Altera os dados de um cliente existente
DELETE cliente/delete/{id}

Desativa o cliente passado como parametro

APIDescription
